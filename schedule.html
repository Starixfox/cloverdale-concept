    Under the hood — for the CREA team

    Enter it once. It shows up everywhere.

    One source of truth

    Artists, attractions, venues and rodeo performances are single records with times and taxonomy terms. This page, performer pages, and venue listings are all views of the same data — no duplicate entry, no drift.

    Filterable by design

    Each record carries day, venue, and type terms. Add a record in the CMS and it is instantly filterable here — the exact behaviour this demo implements in the browser.

    Season-aware

    Records can carry in-season and off-season versions with scheduled publication, so the site flips between event mode and year-round mode without rebuilding pages.
